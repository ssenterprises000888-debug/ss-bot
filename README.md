# 🤖 SS Enterprises Telegram Bot

AI-powered bot for SS Enterprises - CCTV, Electrical, Computer/Laptop repair & Intercom services.

## Features
- ✅ Admin Dashboard with Broadcast
- ✅ AI Conversations in Hinglish
- ✅ Automatic Lead Collection
- ✅ Technician Updates

## Commands
- `/start` - Start the bot
- `/broadcast` - Admin only

## Deployment
Deployed on Render.com

## Tech Stack
- Python 3.9+
- python-telegram-bot
- Google Gemini AI
- aiohttp
